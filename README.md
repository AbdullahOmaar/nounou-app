# نونو — نظام إدارة الحضانات

نظام إدارة حضانات متعدد الحضانات من اليوم الأول: تقرير يومي وصور
خاصة لكل طفل عبر بوابة ولي أمر بروابط واتساب موقعة (بلا تطبيق ولا
حساب لولي الأمر)، رسوم شهرية بباقات فصول وخصم إخوات مع تحصيل
نقدي/InstaPay/Vodafone Cash بإثباتات تُراجَع، وحضور واستلام آمن
من قائمة مصرح لهم + قوائم باص بسيطة. عربي + إنجليزي من اليوم
الأول، وواجهة أزرار كبيرة وخطوات قليلة لطاقم مختلط التقنية.

> حالة المشروع: **الكود مكتمل ومُتحقق محلياً بالكامل** (`npm run
> check` أخضر: lint + build + بوابة i18n + ٨٦ اختبار وحدة + مجموعة
> تفويض ١١٨ فحصاً جاهزة للتشغيل الحي). ملحوظة CI: الـ workflow
> سليم والوظائف تُنشأ، لكن GitHub Actions محجوب حالياً على مستوى
> فوترة الحساب نفسه («account payments have failed» — مسألة مالك)؛
> البوابة المحلية الكاملة هي العاملة حتى يُحسم. النشر الحي ينتظر خطوتي بنية
> بيد المالك (إنشاء مشروع Supabase + منحة فريق Vercel) — التسلسل
> الكامل في `docs/ACTIVATION.md`. حساب الديمو عند التفعيل:
> demo@nounou-app.com / Demo123456 (بيانات وهمية واضحة فقط).

## التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة | React 19 + Vite + TypeScript (strict) |
| التنسيق | Tailwind CSS v4 (هوية الشركة: نيلي/سماوي/كهرماني + ثيم داكن) |
| البيانات | Supabase (PostgreSQL + Auth + RLS + Storage) |
| جلب البيانات | TanStack Query |
| التنقّل | React Router |
| الاختبارات | Vitest + مجموعة تفويض حية (Python) + E2E دخاني (Puppeteer) |

## التشغيل المحلي

```bash
npm install
cp .env.example .env.local   # املأ قيم مشروع Supabase الخاص بنونو
npm run dev                  # http://localhost:5173
npm run check                # البوابة الكاملة قبل أي commit
```

## الوثائق

- `docs/ACTIVATION.md` — التفعيل الحي خطوة بخطوة (هجرات/بذرة/نشر/بوابات).
- `docs/OPERATIONS.md` — دليل تشغيل البايلوت لصاحب الحضانة وطاقمها.
- `docs/REUSE-MAP.md` — خريطة إعادة الاستخدام من تطبيق المدرس ومصدر كل نمط.
- `docs/DEPENDENCY-POLICY.md` + `docs/INCIDENT-RUNBOOK.md` + `SECURITY.md`.
- قرارات المنتج المحسومة بتفويض المالك: ملف `DECISIONS.md` في
  ملفات هدف المشروع «نونو» (كل افتراض موسوم «يُتحقق منه مع البايلوت»).

## قواعد صلبة

- المالية (فواتير/مدفوعات/إثباتات) لمالك الحضانة فقط في RLS —
  لا مفتاح صلاحية مالية للمشرفات أصلاً.
- توكنات البوابة تُخزن hash ‏(SHA-256) فقط، وصور الأطفال لا تخرج
  إلا عبر RPC محروسة بالتوكن مع فحص موافقة التصوير لحظة العرض.
- لا بيانات أطفال حقيقية في أي بيئة — بيانات تجريبية واضحة فقط.
- الهجرات statement-by-statement عبر `run_migration.py` فقط.
