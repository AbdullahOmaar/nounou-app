# حزمة تهيئة البايلوت — «نونو»

مواد جاهزة ليوم وصول أول حضانة حقيقية، محضّرة مسبقاً في دفعة 3A-339
حتى لا يتوقف الإطلاق على تحضير لحظي. **تحضير فقط: لا تواصل مع أي
حضانة هنا — التواصل والتوقيت قرار المالك وحده.**

| الملف | ما هو | لمن |
|---|---|---|
| `import-template.csv` | قالب استيراد الأطفال (ترويسات عربية مطابقة لمنطق الاستيراد + ٣ صفوف أمثلة وهمية واضحة). يُفتح في Excel ويُعبأ ويُرفع من شاشة الأطفال | إدارة الحضانة |
| `pilot-setup-checklist.md` | تسلسل تهيئة مرقم + جدول افتراضات القرارات ق١–ق١٤ مقابل ضبطها في النظام + فحوص ما قبل أول يوم | فريق التهيئة |
| `training-cards.md` | ٣ بطاقات تدريب (مالك/مشرفة فصل/مشرفة باص) تُنسخ في واتساب كما هي | طاقم الحضانة |

قبل أن يصل لحضانة.
