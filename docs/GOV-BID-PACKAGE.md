# حزمة المزايدة الحكومية (5.7)

فهرس جاهزية للمناقصات: كل بند مربوط بوثيقة/دليل قائم —
وما ليس جاهزاً مكتوب صراحة (حزمة ناقصة معلنة خير من
حزمة مكتملة كاذبة).

## الأمن والخصوصية
- نموذج عزل المستأجرين: RLS على كل الجداول بمساعدات
  عضوية فقط؛ المال مالك-فقط بنيوياً (لا مفتاح صلاحية
  طاقم للمال إطلاقاً).
- جناح اختبارات تفويض حي (200+ فحص) يعمل ضد الإنتاج
  التجريبي مع كل تغيير — `scripts/authz_tests.py`.
- قانون 151/2020: سجل معالجة + حقوق أصحاب البيانات +
  سجل مشاهدات صور + حذف موثق عند الطلب (4.13/4.14) —
  `docs/DATA-PROTECTION.md`.
- المفاتيح: مفاتيح Supabase الحديثة فقط؛ القديمة معطلة
  ومتحقق 401 (3A-695). لا بيانات أطفال حقيقية في أي
  بيئة تطوير — تجريبي فقط.

## إقامة البيانات — بند مفتوح بأمانة
- الاستضافة الحالية: Supabase eu-west-1 (أيرلندا).
- أي اشتراط إقامة داخل مصر = مشروع نقل منفصل بقرار
  مالك؛ لا يُوعد به في مزايدة قبل حسمه.

## الاستمرارية
- نسخ احتياطي + تدريب استعادة محلي موثق ومتكرر
  (restore drill) — `docs/INFRASTRUCTURE.md`.
- خروج كريم موثق: تصدير كامل + سماح 30 يوماً + حذف
  موثق (4.14) — البائع لا يحتجز بيانات الجهة أبداً.

## الجاهزية التشغيلية
- ملف جاهزية الترخيص للجهة المشغّلة (4.11/4.12) —
  `docs/LICENSING.md`؛ تتبع خطوات ومواعيد تجديد.
- إدارة فروع متعددة لمشغّل واحد (4.19) —
  `docs/BRANCHES.md` (الدمج المالي HQ فيز لاحقة —
  يُذكر كما هو إن سُئل).

## SLA مقترح (مسودة لقرار تجاري)
- توافر مستهدف 99.5% شهرياً (قياس خارجي عند التعاقد).
- دعم: Sev-1 رد ≤ 15 دقيقة (نموذج الدعم الموثق في
  حزمة ١٧ من خط البحث).
- لا تُوقَّع أرقام أعلى من القدرة الفعلية — تُراجع
  عند كل مزايدة.

## فجوات معلنة
- لا شهادات SOC 2 / ISO 27001 بعد (ملف جاهزية ISO
  9001 داخلي فقط — 4.10).
- الإقامة المحلية غير محسومة (فوق).
- الدفع الأونلاين قرار مالك لم يُحسم (6.2) — المناقصات
  المتطلبة له تُستبعد حتى الحسم.
