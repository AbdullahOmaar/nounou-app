# دليل التدقيق البصري للموبايل (Mobile Visual Audit)

يحتوي هذا المجلد على مخرجات وأصول الفحص البصري وقابلية الاستخدام لتطبيق نونو على شاشات الموبايل الحقيقية تلبيةً للمهمة [3A-336](https://linear.app/3a-agent/issue/3A-336).

## المحتويات

- **[AUDIT-REPORT.md](./AUDIT-REPORT.md)**: تقرير الفحص البصري الشامل (الملخص، المنهجية، الإصلاحات، جدول الشاشات الـ 25، قياسات الأداء المعملي).
- **[audit-results.json](./audit-results.json)**: النتائج التفصيلية لـ 100 فحص بصري مبرمج (اتجاه النص، التجاوز الأفقي، قياسات أهداف اللمس، أزمنة الأداء).
- **[screenshots/](./screenshots/)**: مجلد يضم 100 لقطة شاشة كاملة (25 شاشة × عرضين 360w و390w × لغتين ar وen).

## تشغيل الفحص آلياً

لتشغيل التدقيق وإعادة توليد لقطات الشاشة والتقرير البرمجي:
```bash
node scripts/audit-runner.mjs
```
*ملاحظة: السكربت يقوم تلقائياً ببناء التطبيق وتشغيل خادم محاكاة Supabase مدمج (`scripts/mock-server.mjs`) على منفذ محلي ثم فحص الشاشات عبر Puppeteer.*
