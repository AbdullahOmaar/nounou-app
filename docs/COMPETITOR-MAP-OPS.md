## الإيقاع
- **شهرياً:** تحديث كامل (أسعار، ميزات، قنوات، متابعون)
  من خط البحث عبر المدير — لا تحديثات جانبية.

## تنبيهات الحركة (تُبلَّغ للمدير فور رصدها)
1. تغيير سعر أو باقة عند أي منافس موثق.
2. إطلاق ميزة تطابق فجواتنا الخمس المعروفة (باص حي،
   مُرسِل واتساب، دفع أونلاين، منهج/معالم، كاميرات).
3. جولة تمويل أو شراكة توزيع (حضانات سلاسل/جهات).
4. دخول لاعب جديد بنفس الشريحة والسعر (تحقق هوية أولاً).
