# إدارة الفروع (4.19)

## المنفذ
- صفحة `/branches` («فروعي»): كل عضويات المستخدم بعدّادات
  سريعة (أطفال نشطون، ومتأخرات للفروع التي يملكها فقط —
  المال مالك-فقط في RLS دائماً) + تبديل فوري للفرع النشط
  (نفس مبدّل «المزيد» القائم) + **إضافة فرع جديد** باسم
  (RPC ‏create_nursery القائم) مع التبديل إليه فوراً.
- لا مهاجرة: العضويات والتبديل والإنشاء قائمة منذ فيز 1؛
  الجديد هو سطح الإدارة الموحد.

## حدود مقصودة (حكم دراسة السوق — حزمة ١٤)
- **لا دمج مالي عبر الفروع (HQ) الآن:** تجميع المقر قراءة-
  موحدة عبر الفروع = فيز لاحقة بمحفزات أدلة (أول مجموعة
  سلاسل حقيقية على المنصة). مشغّل المنصة يرى العدّادات
  العابرة في 4.18 لأغراض التشغيل فقط.
- **مدير فرع لا يرى فرعاً شقيقاً** إلا بعضوية صريحة فيه —
  العضوية هي حد الرؤية الوحيد.
- **نقل طفل بين فرعين** يُبنى مع HQ بقاعدة مال صريحة
  (متأخرات عند المُرسل، مقدم كائتمان عند المستقبل) — لا
  نقل صامت قبلها.
