# خريطة إعادة الاستخدام — من أين جاء كل جزء في «نونو»؟

نونو منتج مستقل في ريبو مستقل. أُخذ هيكل تطبيق المدرس
(`teacher-app-identity2` — مرجع قراءة فقط، لم يُعدَّل أبداً) كشاسيه،
ثم أُعيدت كتابة طبقة الميزات كاملة على أنماطه المجرّبة. القرار وسببه:
الطبقة المنسوخة حرفياً (~22K سطر) كانت شديدة الارتباط بشكل المدرس
(درجات/امتحانات/واجبات/ماسكوت) لدرجة أن تكييفها سطراً بسطر كان
سينتج جودة أدنى من إعادة كتابة نظيفة على نفس الأنماط.

## منسوخ كما هو تقريباً (شاسيه)

| الجزء | المصدر في المدرس | ملاحظات |
|---|---|---|
| `src/components/ui/*` (Button/Card/Sheet/قوائم/حالات/نموذج) | نفسه | أُضيف `ConfirmSheet` جديد (تأكيد خفيف) لأن الشاسيه لا يملك إلا نمط «اكتب الاسم» الثقيل |
| `src/lib/` (supabase client، invalidate، routePrefetch، csv، phone) | نفسه | `format.ts` أُعيدت كتابته لمفاهيم نونو |
| إطار i18n (t/locale/format/plural) | نفسه | القواميس كلها جديدة (١٨ namespace × لغتين) |
| `src/hooks/useTheme`، أنماط TanStack Query | نفسه | مفتاح التخزين صار `nounou-theme` |
| بنية الهجرات وRLS helpers وأنماط التوكن hash-only | هجرات المدرس 0001–0029 | أُعيد تطبيقها على مخطط نونو (0001–0010) |
| `scripts/authz_tests.py` (الهيكل والآلية) | نفسه | أُعيدت كتابة الفحوص لمخطط نونو: ١٠٦ فحوص |
| `e2e/run.mjs` (الهيكل والريلاي) | نفسه | التدفقات الستة أُعيدت كتابتها لشاشات نونو وبذرتها |
| بوابات CI (check + gitleaks) و`scripts/check-i18n.mjs` | نفسه | قائمة استثناءات i18n أُعيدت كتابتها (ملف واحد موثق) |
| Edge Function نمط signed URLs | `send-push` إلخ (نمط) | `portal-media` جديدة: تحقق RPC بخدمة فقط + رابط موقّع ١٥ دقيقة |

## أُعيدت كتابته على الأنماط (ميزات)

الأطفال/الفصول/يوم الفصل والحضور (مع طابور أوفلاين بنفس فكرة المدرس
لكن بمفتاح تخزين ودمج خاص بنونو)/الفواتير وخطة الإصدار النقية/
الإثباتات/التقارير والصور (ضغط canvas بنفس حدود الدراسة)/البوابة
(توكنات hash-only ٣٠ يوماً لكل وصي)/الباص/الإعلانات/الإشعارات
(تنبيهات خلف الجرس فقط — قاعدة مالك ثابتة)/الإعدادات والأعضاء/
الرئيسية/سجل النشاط/التصدير.

## حُذف ولم يُنقل (خاص بالمدرس)

الدرجات والامتحانات والواجبات والجدول وبوابة الطالب والتحليلات
والخزنة، والدخول برقم الهاتف/واتساب OTP، والإشعارات Push، والعلامة
البيضاء، و**دُفّي الماسكوت** (خاص بتطبيق المدرس بقرار هوية) — نونو
له علامة «برعم» مجردة بألوان الشركة في `src/components/mascot/`
كواجهة متوافقة مع مكوّنات الشاسيه التي تتوقع Mascot API.

## قرارات المنتج

كل قرارات الأسئلة المفتوحة (ق١–ق١٧) موثقة في ملف هدف المشروع
`DECISIONS.md` — كل افتراض موسوم «يُتحقق منه مع البايلوت» مع سببه
وقابلية عكسه.
