# العمل دون اتصال (415)

## الحضور — منذ فيز 1
طابور localStorage + كاتب `networkMode: 'always'` + شارة عدّاد.

## التقارير والصور — مهمة 2.10
- **التقارير:** أي فشل حفظ (ما عدا رفض «طفل غائب» الصريح) يُطابَق
  في `nounou-report-queue-v1` (localStorage، آخر كتابة تغلب لكل
  طفل/يوم) ويُرفع للمستخدم كـ«اتحفظت على الجهاز».
- **الصور:** الـBlobs في IndexedDB (`nounou-offline/photo-queue`)
  لأن localStorage لا تسعها؛ تُرفع عند عودة الاتصال عبر نفس
  `uploadPhotos` (الموافقة والسقف يُعاد فحصهما عند الرفع الفعلي).
- **حراسة الفقدان الصامت (S3):** العدّاد المعلّق ظاهر دائماً في
  صفحة التقارير، والتفريغ عند `online` + كل 30 ثانية + عند فتح
  الصفحة؛ الفشل يُبقي العملية في الطابور — لا شيء يعيش في ذاكرة
  React Query وحدها.
- **المال لا يدخل هنا أبداً** (قرار 1.1: المال أونلاين فقط).
